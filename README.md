# Bookstore Intelligence Scraper

## Project Overview
This project scrapes book information from Books to Scrape using Python, Requests, BeautifulSoup, and Pandas.

## Data Collected
- Book title
- Price
- Star rating
- Availability
- Product page URL

## Analysis
The project analyzes book prices, ratings, and availability, identifies highly rated books, and solves a £100 purchasing challenge.

## How to Run
Open the notebook in Google Colab and run the cells from top to bottom.

## Output
The scraper generates a CSV file named `competitor_books.csv`.
